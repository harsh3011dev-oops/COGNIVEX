================================================================================
IF SOMETHING GOES WRONG
================================================================================

ISSUE: Backend logs show "test_results insert failed"
  ❌ Status: Insert failed but quiz still works
  Possible causes:
    1. Missing columns on test_results table
    2. User not in user_profile table
    3. Database permission/RLS issue
  Action: Check backend error message, then:
    - Run: ALTER TABLE test_results ADD COLUMN IF NOT EXISTS subject VARCHAR(255);
    - Verify user exists in user_profile
    - Check Supabase logs for RLS errors


ISSUE: Dashboard still shows all 0s
  ✅ Quiz worked (200 OK response shown)
  ✅ Backend logged successful insert
  ✅ Database has new row
  But: Dashboard doesn't show it
  Solution: 
    1. Hard refresh dashboard: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
    2. Wait 2 seconds
    3. Check again


ISSUE: No backend logs appear
  ✅ Check backend terminal is active
  ✅ Restart backend: Ctrl+C then npm run dev
  ✅ Submit quiz again


ISSUE: 500 error from quiz submission
  ❌ Something broke in submitQuiz function
  Action:
    1. Check backend error logs for details
    2. Verify database connection
    3. Restart backend


ISSUE: Database query returns no rows
  ❌ INSERT never executed
  Possible causes:
    1. Code changes not applied
    2. Backend not restarted after changes
    3. Wrong user ID
  Action:
    1. Verify code changes are in questionController.js
    2. Restart backend: Ctrl+C then npm run dev
    3. Submit quiz again

DATABASE QUERIES TO RUN
================================================================================

Query 1: Check if row exists
  SELECT * FROM test_results 
  WHERE user_id = 'YOUR_USER_ID' 
  ORDER BY created_at DESC LIMIT 5;
  
  Expected: See your quiz with all fields populated


Query 2: Count total quizzes for user
  SELECT COUNT(*) FROM test_results WHERE user_id = 'YOUR_USER_ID';
  
  Expected: Should increment after each quiz


Query 3: View columns on test_results
  SELECT column_name, data_type FROM information_schema.columns 
  WHERE table_name = 'test_results';
  
  Expected: Should see:
    - id (uuid)
    - user_id (uuid)
    - subject (varchar)
    - score (integer)
    - total_questions (integer)
    - questions_attempted (integer)
    - questions_correct (integer)
    - accuracy (integer)
    - created_at (timestamp)


Query 4: Check your latest quiz result
  SELECT 
    subject,
    score,
    accuracy,
    questions_attempted,
    questions_correct,
    created_at 
  FROM test_results 
  WHERE user_id = 'YOUR_USER_ID'
  ORDER BY created_at DESC 
  LIMIT 1;
  
  Expected: Recent quiz with all metrics


Query 5: Calculate what dashboard will show
  SELECT 
    SUM(questions_attempted) as total_attempted,
    ROUND(AVG(accuracy)) as avg_accuracy,
    COUNT(*) as total_tests,
    subject
  FROM test_results 
  WHERE user_id = 'YOUR_USER_ID'
  GROUP BY subject;
  
  This shows what dashboard metrics will display

================================================================================
BACKEND LOG MESSAGES EXPLAINED
================================================================================

You should see these logs in this order:

1. "submitQuiz request: { userId: '...', answerCount: 10 }"
   → Quiz submission started, 10 questions received

2. "Inserting into test_results: { userId: '...', subject: 'Full Test', score: 75, total: 10, correctCount: 7, accuracy: 75 }"
   → About to insert into database, here's what we're inserting

3. "✅ test_results saved successfully, id: 1a2b3c4d..."
   → INSERT succeeded, here's the new row ID
   → ✅ This is the SUCCESS indicator

4. "submitQuiz success: { userId: '...', total: 10, correctCount: 7, score: 75 }"
   → Quiz grading complete, about to send response to frontend


If you DON'T see log 3 (✅ success message):
  → Check log output for error message
  → "test_results insert failed" or similar
  → Error details will be in the logs
