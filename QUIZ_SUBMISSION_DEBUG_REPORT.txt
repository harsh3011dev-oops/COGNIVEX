================================================================================
ROOT CAUSE ANALYSIS
================================================================================

Issue 1: No INSERT into test_results
  - submitQuiz controller calculates score, accuracy, questions correctly
  - BUT only inserts into quiz_attempts (one row per question)
  - test_results table never receives any data
  - Result: test_results is completely empty

Issue 2: test_results table schema is incomplete
  - Missing `subject` column (needed for subject accuracy breakdown)
  - Missing `questions_attempted`/`questions_correct` (has only total_questions)
  - Dashboard queries expect these fields
  - Result: Even if data were inserted, calculations would be incomplete

Issue 3: Dashboard queries expect fields that don't exist
  - dashboardController expects: test.subject, test.questions_attempted, test.questions_correct
  - test_results table has: score, total_questions, accuracy
  - Mismatch causes undefined/null values in calculations

Cascading Effect:
  No INSERT → test_results empty
    ↓
  Dashboard queries return empty array
    ↓
  All metrics show 0/empty
    ↓
  Dashboard doesn't update after quiz
