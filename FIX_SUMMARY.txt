PROBLEM IDENTIFIED
================================================================================
Quiz submission worked correctly (200 OK) but:
- test_results table remained COMPLETELY EMPTY
- Dashboard queried test_results → got empty array
- Dashboard showed 0s and empty sections
- Root cause: submitQuiz() NEVER inserted into test_results
- Only inserted into quiz_attempts (per-question data)

FLOW BROKEN:
  Quiz Submit → Score Calculated ✅ → quiz_attempts insert ✅ → test_results insert ❌
  Result: Dashboard has no data to display


SOLUTION IMPLEMENTED
================================================================================
Modified: backend/src/controllers/questionController.js
Lines: 430-486 (57 lines added)

What was added:
  After calculating quiz score and inserting into quiz_attempts,
  the code now ALSO inserts ONE row into test_results with:
  - user_id (who took quiz)
  - subject (quiz subject)
  - score (0-100)
  - total_questions (number of questions)
  - questions_attempted (same as total)
  - questions_correct (number correct)
  - accuracy (0-100)

Key features:
  ✅ Non-fatal error handling (quiz submission won't fail if insert fails)
  ✅ Full logging for debugging
  ✅ Subject extraction with fallbacks
  ✅ No changes to authentication
  ✅ No changes to quiz grading logic

ERROR HANDLING
================================================================================

This implementation uses NON-FATAL error handling:

If test_results insert SUCCEEDS:
  ✅ Quiz submission returns 200 OK
  ✅ Database updated
  ✅ Dashboard will show new data
  Log: "✅ test_results saved successfully, id: ..."

If test_results insert FAILS:
  ✅ Quiz submission still returns 200 OK (doesn't crash)
  ✅ User sees quiz results (score already calculated)
  ❌ Dashboard won't update (but doesn't break)
  Log: "test_results insert failed (non-fatal): ..."

Why non-fatal?
  - Quiz submission should never fail due to optional dashboard feature
  - User's score is already calculated and shown
  - Dashboard update is secondary concern
  - Full logging ensures we can debug if needed
