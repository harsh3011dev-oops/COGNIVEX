================================================================================
ERROR HANDLING STRATEGY
================================================================================

This implementation uses NON-FATAL ERROR HANDLING:

Scenario 1: test_results insert succeeds
  Status: ✅ Best case
  Result: Database updated, dashboard will show data
  Log: "✅ test_results saved successfully, id: <uuid>"

Scenario 2: test_results insert fails (DB error)
  Status: ⚠️ Degraded
  Result: Quiz submission still returns 200 OK, score shown to user
          Dashboard doesn't update (but no crash)
  Log: "test_results insert failed (non-fatal): <error details>"
  Impact: User sees quiz results, but dashboard won't update
  Recovery: Dashboard updates when user takes another quiz

Scenario 3: Unexpected exception
  Status: ⚠️ Rare edge case
  Result: Quiz submission still returns 200 OK
  Log: "test_results insert exception (non-fatal): <error>"
  Impact: Minimal
  Recovery: Automatic retry on next quiz

Why Non-Fatal?
  - User's quiz score is already calculated
  - User gets immediate feedback (quiz results page)
  - Dashboard update is secondary concern
  - Quiz submission should never fail due to dashboard feature
  - Errors are fully logged for debugging

================================================================================
TROUBLESHOOTING
================================================================================

Problem 1: Backend shows error "column 'subject' does not exist"
  Cause: test_results table schema not updated
  Solution: Need to run ALTER TABLE commands to add columns
  Note: This would only happen if schema migrations weren't applied

Problem 2: Backend shows "violates foreign key constraint"
  Cause: user_id doesn't exist in user_profile table
  Solution: Ensure user is properly registered before taking quiz
  Check: Make sure you're logged in and profile is created

Problem 3: No logs appear in backend console
  Cause: Backend not running or logs not visible
  Solution: 
    - Check backend terminal is showing logs
    - Try: npm run dev in backend directory
    - Restart if needed

Problem 4: Dashboard still shows 0s after quiz
  Possible Causes:
    a) test_results insert failed (check backend logs)
    b) Dashboard cache (try hard refresh: Ctrl+Shift+R)
    c) Wrong user ID (verify you're logged in as same user)
  Solution:
    - Check backend logs for "test_results insert failed"
    - Hard refresh dashboard (Ctrl+F5)
    - Check database directly to confirm row exists
    - Try submitting another quiz

Problem 5: Quiz submission fails (500 error)
  Cause: Something broke in submitQuiz function
  Solution:
    - Check backend logs for error details
    - Verify quiz_attempts table still works
    - Check database connection
    - Restart backend

Problem 6: "test_results insert failed (non-fatal)" in logs
  Status: Not critical
  Meaning: Insert tried but hit DB error
  Impact: Quiz still works, dashboard won't update
  Solution:
    - Check error details in logs
    - Could be permission (RLS) issue
    - Could be missing columns
    - Run SELECT * FROM test_results LIMIT 1 to check structure
